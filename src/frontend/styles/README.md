# Styles

This directory contains all styling-related files for your frontend application.

## Contents

- **Global styles** - CSS variables, reset, base styles
- **Theme files** - Color palettes, typography, spacing tokens
- **Component styles** - Component-specific CSS/modules
- **Utility classes** - Helper classes for common patterns
- **Animation styles** - Transitions, keyframes, motion effects

## File Types

- `.css` - Standard CSS files
- `.scss` / `.sass` - Sass/SCSS preprocessor files
- `.module.css` - CSS Modules for component-scoped styles
- `.css.ts` - CSS-in-JS (if using libraries like vanilla-extract)

## Guidelines

- Use CSS custom properties for theming
- Follow a consistent naming convention (BEM, utility-first, etc.)
- Keep styles organized by component or feature
- Use responsive design patterns
- Consider using a CSS-in-JS solution or CSS Modules for better scoping
