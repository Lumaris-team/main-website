L'école est bruyante.

Lumaris est une plateforme éducative intelligente : gestion scolaire via ÉcoleDirecte, tuteur IA sur Cloudflare Workers AI, espace de fichiers sur MEGA.nz, et des notifications qui vous gardent une longueur d'avance — le tout dans un tableau de bord apaisé.

L'équipe

Une org, cinq dépôts.

Lumaris est construite et maintenue par l'organisation Lumaris-team — « équipe de développeurs qui gère le site Lumaris », basée en France, propriétaire vérifiée de lumaris.fr.eu.org. Tout est open source sous licence MIT.

La stack

Serverless, partout dans le monde.

Cloudflare Workers pour le calcul, D1 pour les données, KV pour le cache, Workers AI pour l'intelligence, MEGA.nz pour les fichiers, Supabase pour l'authentification.
