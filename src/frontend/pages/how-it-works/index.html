The journey

Four steps, zero friction.

Each step maps to a real backend module in the client worker. Nothing here is marketing fluff.

    Step 03, in detail

    The toolbox.

    Three real tools ship in the dashboard, served by /api/tools/*, /api/pomodoro/* and the cache layer. Not mockups — working code.

    Scientific calculator

    Full expression engine with functions, memory and history. Every result can be pushed to the synced history.

    • Trigonometry, logs, powers, roots
    • History synced — GET / POST / DELETE calcul-history
    • Second-mode keys for advanced ops
    GET /api/tools/calcul-history

    Unit converter

    Length, volume and capacity from local factor tables — plus live currency via exchange-rate API.

    • 20+ length units, 30+ volume, 40+ capacity
    • Light-years, parsecs, barrels, magnums…
    • Currency at real rates, 6-decimal precision
    POST /api/tools/convert

    Pomodoro timer

    Focus sessions persisted per day with streak tracking. State survives reloads via cache + storage.

    • Work / break cycles with day stats
    • Streaks and per-day aggregates
    • Custom durations in settings
    /api/pomodoro/* + cache layer
